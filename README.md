## Descripción

Eco-Commerce es una página web para la gestión de un kiosco. Cuenta con un sistema de inicio de sesión que permite registrar nuevos usuarios y recuperar la contraseña en caso de olvido.

Además, la plataforma permite cargar y administrar productos, así como registrar usuarios y asignarles permisos especiales, incluyendo el rol de administrador. De esta manera, se facilita la organización y gestión del kiosco desde un solo lugar.

El proyecto fue desarrollado utilizando JavaScript, Node.js, HTML y CSS.
